# Data Analytics Portfolio

Portfolio of hands-on data analytics and business intelligence projects covering data preparation, transformation, integration, analysis, visualization, reporting, and AI-assisted analytics.

## Alteryx

Built end-to-end Alteryx Designer workflows for data preparation, transformation, integration, aggregation, and automated reporting. Applied data cleansing, filtering, formulas, sorting, sampling, joins, unions, running totals, weighted averages, and multi-field transformations. Created automated reporting workflows with tables, charts, layouts, and multi-page PDF output.

**Tools & Skills:** Alteryx Designer, Data Preparation, Data Transformation, Join, Join Multiple, Union, Summarize, Running Total, Weighted Average, Reporting

## Microsoft Fabric

Built an end-to-end sales analytics solution in Microsoft Fabric, covering data ingestion, Lakehouse architecture, SQL transformations, semantic modeling, DAX, and Power BI reporting. Created FactSales and dimension tables, designed a star-schema semantic model, developed KPI measures, and built an interactive executive sales dashboard.

**Tools & Skills:** Microsoft Fabric, Fabric Lakehouse, Data Pipelines, SQL, Semantic Models, Star Schema, DAX, Power BI

## Power BI Copilot

Applied Power BI Copilot for AI-assisted data analysis and report development. Generated executive reporting content, analyzed sales and profitability performance, identified KPI insights, and used Copilot to generate and test DAX for Month-over-Month Sales Growth.

**Tools & Skills:** Power BI Copilot, Generative AI, Prompt Engineering, DAX, Data Analysis, Business Intelligence, Executive Reporting

## Power BI

Developed interactive Power BI dashboards with drill-down analysis, DAX measures, Power Query transformations, data modeling, and interactive visualizations.

**Tools & Skills:** Power BI, DAX, Power Query, Data Modeling, Data Visualization

## Tableau

Developed interactive Tableau dashboards for financial and customer analytics, including a stock performance dashboard and UK bank customer analysis. Used multiple data sources, calculated fields, parameters, filters, KPI cards, and interactive dashboard actions.

**Tools & Skills:** Tableau, Data Visualization, Dashboard Design, Calculated Fields, Parameters, Filters, Data Analysis

## SQL

Designed and implemented a relational database with six tables, including primary keys, foreign key constraints, and referential integrity. Developed analytical queries using JOINs, subqueries, UNION ALL, window functions, GROUP BY, aggregations, and date functions, and created reporting views and a fact table for Power BI integration.

**Tools & Skills:** SQL, Relational Databases, JOINs, Subqueries, Window Functions, Aggregations, Views, Data Modeling

## Python

Performed end-to-end exploratory data analysis including data cleaning, outlier detection, univariate, bivariate, and multivariate analysis, statistical analysis, and data visualization.

**Tools & Skills:** Python, pandas, matplotlib, seaborn, plotly, statsmodels, scikit-learn
