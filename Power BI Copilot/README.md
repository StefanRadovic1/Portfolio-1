# Power BI Copilot

AI-assisted data analysis and report development using Microsoft Power BI Copilot.

## Use Cases

- Generated an executive sales performance report page from the existing semantic model.
- Generated an executive management summary highlighting key KPIs, sales and profitability trends, customer performance, and areas requiring attention.
- Performed targeted profitability analysis to identify the most profitable product category, key subcategory profit drivers, and loss-making areas.
- Used Copilot to generate and test a DAX query for Month-over-Month Sales Growth %.

## Skills Demonstrated

Power BI Copilot, Generative AI, Prompt Engineering, DAX, Data Analysis, Business Intelligence, Executive Reporting
