# Alteryx Data Preparation & Reporting

This project demonstrates end-to-end data preparation, transformation, integration, analysis, and automated reporting using Alteryx Designer.

## Workflow

- Cleaned and prepared sales data, including missing values and date transformations.
- Applied filtering, sorting, sampling, formula-based and multi-field transformations.
- Integrated sales, store, and employee datasets using Join, Join Multiple, and Union.
- Performed aggregations, running totals, averages, and weighted-average calculations.
- Created tables and visualizations and generated an automated multi-page PDF sales report.

## Tools & Techniques

Alteryx Designer: Data Cleansing, Filter, Formula, Select, Sort, Sample, Multi-Field Formula, Join, Join Multiple, Union, Summarize, Running Total, Weighted Average, Table, Chart, Layout, and Render.

## Output

The final workflow produces a business-ready PDF report containing sales tables and visualizations by year and city.
